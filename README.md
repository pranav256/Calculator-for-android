# Calculator for Android

A native Android arithmetic calculator application developed in Java using the Android SDK.

## Features

- **Native Android UI:** Clean XML linear layout with touch-optimized buttons and formatted display.
- **Operator Precedence:** Safe expression evaluation and error handling for division by zero.
- **Orientation Support:** Responsive UI adapting between portrait and landscape modes.

## Tech Stack

- Java
- Android SDK (API Level 21+)
- XML Layouts

## Build

Open the project in Android Studio, sync Gradle, and build the APK or run on an Android emulator/device.
